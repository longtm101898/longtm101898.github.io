IWorkForNSW

Sep 2025 to present AdNeo Full-stack engineer iworkfor.nsw.gov.au

The official recruitment platform of the New South Wales Government.

Recruitment features, accessibility and secure integrations.

Stack: React, Next.js, TypeScript, C#/.NET, Blazor, SQL Server and Azure SQL, Azure Functions, Azure DevOps, Mend SCA

01 The challenge

Deliver recruitment features while addressing accessibility and security audit findings. The work also covered NSW Health data feeds and integrations with external applicant tracking systems.

02 Technical approach

Accessibility and security. Improved keyboard navigation and screen-reader support, remediated penetration testing and Mend SCA findings, and hardened authentication and session handling.

Data and integrations. Optimised NSW Health feeds that previously took ~34 minutes for 1,740 changed records; introduced mapping caches, deduplication and four-worker parallelism, and validated 2,500 records in 9.32 minutes in UAT. Validated integrations with PageUp, SAP SuccessFactors and Taleo.

Web performance and releases. Optimised server-side rendering and caching, and stabilised regression testing in Azure DevOps.

03 My contribution

As a full-stack engineer at AdNeo, I delivered recruitment features in React and Next.js, enhanced the .NET APIs and Blazor CMS, and maintained React Native mobile features. My scope also included the audit remediation, feed optimisation and integration validation described above.
